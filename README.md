
# Student Score Manager

A beginner Python project for managing student names and scores.

## Features

- Get student name and score from the user
- Support names and surnames
- Allow spaces and underscores in student names
- Validate student name input
- Validate student score input
- Calculate basic class statistics
- Display student information

## Technologies

- Python 3

## What I Learned

While developing this project, I practiced:

- Variables
- Input and output
- Strings
- Lists
- Dictionaries
- Conditions
- Loops
- `split()` and `rsplit()`
- `all()`
- `isalpha()`
- Input validation
- Basic data analysis

## Example

The program can accept student information such as:

    reza_ahmadi 18

or:

    reza ahmadi 18

The program separates the student name from the score and validates the input.
